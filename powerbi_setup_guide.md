# 📊 Mumbai Apartment Price Tracker — PowerBI Setup Guide

## Overview
This guide walks you through connecting PowerBI Desktop to the data generated by this project and building a price trends dashboard for Mumbai apartments.

---

## Prerequisites
- [PowerBI Desktop](https://powerbi.microsoft.com/en-us/desktop/) installed (free)
- Run the scraper at least once: `python run.py`  
  *(Or for instant demo data: `python generate_sample_data.py`)*
- A CSV file will appear in the `exports/` folder.

---

## Step 1 — Load Data into PowerBI

1. Open **PowerBI Desktop**
2. Click **Home → Get Data → Text/CSV**
3. Browse to your `ApartmentTracker\exports\mumbai_apartments_XXXXXX.csv`
4. Click **Load**

> 💡 **Tip:** To always load the latest CSV automatically, use **Transform Data → Source** and point to the most recent file.

---

## Step 2 — Set Correct Data Types

Go to **Home → Transform Data** (Power Query Editor):

| Column | Set Type To |
|---|---|
| `scraped_at` | Date/Time |
| `price_lakh` | Decimal Number |
| `area_sqft` | Whole Number |
| `bhk` | Whole Number |
| `locality` | Text |
| `city` | Text |

Click **Close & Apply**.

---

## Step 3 — Build the Dashboard

### 📈 Chart 1: Average Price Trend Over Time
- **Visual:** Line Chart
- **X-Axis:** `scraped_at` (set to Date hierarchy → Day)
- **Y-Axis:** `price_lakh` (Aggregation: **Average**)
- **Legend:** `bhk` (to show separate lines per BHK type)
- **Title:** *"Mumbai Apartment Avg Price (₹ Lakh) Over Time"*

---

### 🏘️ Chart 2: Average Price by Locality
- **Visual:** Clustered Bar Chart
- **Y-Axis:** `locality`
- **X-Axis:** `price_lakh` (Average)
- **Sort:** Descending by price
- **Title:** *"Average Apartment Price by Locality"*

---

### 🏠 Chart 3: BHK Distribution (Pie Chart)
- **Visual:** Pie Chart or Donut Chart
- **Legend:** `bhk`
- **Values:** Count of `id`
- **Title:** *"Listings by BHK Type"*

---

### 📐 Chart 4: Area vs. Price Scatter Plot
- **Visual:** Scatter Chart
- **X-Axis:** `area_sqft` (Average)
- **Y-Axis:** `price_lakh` (Average)
- **Details:** `locality`
- **Legend:** `bhk`
- **Title:** *"Price vs. Area by Locality"*

---

### 🔢 KPI Cards (Add at the top of the dashboard)
Add 4 **Card** visuals:

| Card Title | Field | Aggregation |
|---|---|---|
| Total Listings | `id` | Count |
| Avg Price (Lakh) | `price_lakh` | Average |
| Avg Area (sqft) | `area_sqft` | Average |
| Localities Tracked | `locality` | Count Distinct |

---

## Step 4 — Add Slicers (Filters)

Add **Slicer** visuals to make the dashboard interactive:

1. **BHK Filter** → Field: `bhk`
2. **Locality Filter** → Field: `locality` (set to Dropdown)
3. **Date Range Filter** → Field: `scraped_at`

---

## Step 5 — Refresh Data

Every time you run `python run.py`, a new CSV is generated.

To refresh in PowerBI:
- Click **Home → Refresh**  
- Or set up **Scheduled Refresh** if you publish to PowerBI Service (requires Pro licence).

---

## 🎨 Suggested Theme
- **Background:** Dark gray (`#1E1E2E`)
- **Accent:** Saffron/Gold (`#F4A300`) — a Mumbai-inspired colour
- **Font:** Segoe UI (PowerBI default)

Apply via: **View → Themes → Browse for themes** → import a JSON theme file.

---

## 💾 Keeping Data Fresh

Run the scraper on a schedule:
```bash
# Runs every 24 hours automatically
python run.py --schedule
```

Or set up a Windows Task Scheduler job to run `python run.py` daily at a specific time.
